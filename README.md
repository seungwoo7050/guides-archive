# 웹 인프라 가이드

웹 요청이 서버에 도착하고 여러 프로세스가 함께 동작하는 과정을 정리하는 저장소입니다.

처음에는 다음 내용을 다룰 예정입니다.

- HTTP 요청과 서버 프로세스
- Docker 이미지와 컨테이너
- 여러 컨테이너의 연결
- 데이터 저장과 재시작
- 게이트웨이, 애플리케이션, 데이터베이스
- 실행 중 문제가 생겼을 때 확인하는 순서

문서는 개념을 설명하고, `exercises/`에는 직접 실행해 볼 수 있는 작은 구현을 둡니다. 세부 범위와 파일 구성은 내용을 작성하면서 조정합니다.

## 대략적인 구성

```text
.
├── README.md
├── docs/
└── exercises/
```

진행 순서는 [`docs/00-roadmap.md`](docs/00-roadmap.md)에 정리합니다.
