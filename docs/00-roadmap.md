# 학습 로드맵

웹 서비스를 실행하는 데 필요한 기초부터 순서대로 정리합니다. 아직 장의 수와 exercise 구성은 확정하지 않습니다.

## 1. 요청과 서버

HTTP 요청과 응답, 주소와 포트, 서버 프로세스의 실행과 종료를 다룹니다.

## 2. 컨테이너

Docker 이미지와 컨테이너의 차이, Dockerfile, 주 프로세스와 파일 수명을 다룹니다.

## 3. 여러 서비스 연결

Compose를 사용해 여러 컨테이너를 연결하고, 내부 네트워크와 영속 저장소를 구분합니다.

## 4. 웹 서비스 구성

게이트웨이, 애플리케이션 실행 환경, 데이터베이스를 나누어 실행하는 구성을 살펴봅니다.

## 5. 시작과 복구

데이터베이스 초기화, 반복 가능한 시작 절차, 상태 검사와 기본적인 장애 확인 방법을 다룹니다.

구체적인 문서와 구현 대상은 작성 과정에서 정리합니다.
